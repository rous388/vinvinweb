# VINVIN · Web de catas y viandas

Proyecto web desarrollado como práctica académica, centrado en la creación de un sitio para VINVIN, una propuesta de catas de vino y maridaje en Almería.

La web incluye varias páginas informativas y de producto, junto con funcionalidades interactivas como:

- cambio de tema claro/oscuro
- carrito con almacenamiento en localStorage
- resumen desplegable del carrito
- notificación visual al añadir productos
- eliminación de productos mediante modal de confirmación
- valoración con estrellas
- control de cantidad en fichas de producto

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
